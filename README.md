# Hi-Lo Game

A modern full-stack implementation of the classic **Hi-Lo card game** built with **NestJS**, **Next.js**, **Prisma**, and **PostgreSQL**, designed for deployment as a Telegram Mini App.

---

## Features

- User Authentication
- Telegram Mini App Integration
- Hi-Lo Gameplay
- Wallet Management
- Betting System
- Admin Dashboard
- Game History
- Statistics & Analytics
- Secure REST API
- Prisma ORM
- PostgreSQL Database

---

### Frontend

## Installation

### Clone

```bash
git clone https://github.com/YOUR_USERNAME/hi-lo-full-stack.git
```

### Backend

```bash
cd backend
npm install
```

### Frontend

```bash
cd frontend
npm install
```

---

## Environment Variables

Create a `.env` file.

Example:

```env
DATABASE_URL=
JWT_SECRET=
TELEGRAM_BOT_TOKEN=
NEXT_PUBLIC_API_URL=
```

---

## Run Backend

```bash
npm run start:dev
```

---

## Run Frontend

```bash
npm run dev
```

---

## Deployment

### Frontend

Deploy using **Vercel**

### Backend

Deploy using **Railway** or **Render**

### Database

Use **Neon PostgreSQL** or **Supabase PostgreSQL**
